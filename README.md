Página temática com três seções lado a lado (Filmes e Séries, Música e Podcasts, Games e Tecnologia), estilizada com os três tipos de CSS.
O código executável está disponível em [`portal.html`](portal.html).

## 🎯 Objetivo

Praticar a estilização de páginas com CSS: inline, interno e externo, classes e IDs, reset de estilo e layout com flexbox.

## 📋 Seções

| Seção | Conteúdo |
|-------|----------|
| Filmes e Séries | Título, 2 imagens e texto explicativo |
| Música e Podcasts | Título, 2 imagens e texto explicativo |
| Games e Tecnologia | Título, 2 imagens e texto explicativo |

## 🧠 Conceitos utilizados

- Três formas de CSS: inline (`style`), interno (`<style>`) e externo (`<link>`)
- Ordem de cascata entre as folhas de estilo
- Seletores de tag, classe e ID
- Comentários em CSS
- Unidades relativas (`em` e `%`)
- Layout com `display: flex`, `flex-grow` e `flex-wrap`
- CSS Reset (Eric Meyer)

## ▶️ Como executar

```bash
git clone https://github.com/Lucaslmx/Ag13_DS_I.git
cd Ag13_DS_I
```

Abra o arquivo `portal.html` no navegador.
